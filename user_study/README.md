# User Study

Code and stimuli for the two human studies in the paper. Each study is a small
[Streamlit](https://streamlit.io) web app. The participant interface is in Korean.

| Folder | Study | Conditions |
|---|---|---|
| `study1_binary_vs_open/` | Study 1: question format | Binary yes/no questions (ProCompNav) vs. open-ended questions (Pooled Independent Matching), 5 paired sets |
| `study2_delivery/` | Study 2: question delivery | Batched (all questions after one long search) vs. interleaved (one question per search interval) |
| `scripts/` | Stimulus preparation and analysis | See below |

**Participant responses are not included in this repository.**

## Stimulus data

The questions shown to participants were taken directly from navigation logs on
CoIN-Bench Val Seen. No question was written by hand.

- `study1_binary_vs_open/data/stimulus_pool_h2.json`: 5 episodes (cabinet, bed,
  table, desk, chair).
- `study2_delivery/data/stimulus_pool.json`: 2 episodes.
- `data/target_images*/ep<id>_target.png`: target-object image for each episode.
- `data/tutorial_target.png`: image used in the tutorial screen.

Fields of each episode record:

| Field | Meaning |
|---|---|
| `ep_id`, `category`, `target_instance_id` | CoIN-Bench episode, target category, and target instance |
| `binary_qs[].prop` | Attribute asked by ProCompNav (`yes_no_result` in the ProCompNav `info.json`) |
| `binary_qs[].gt_answer` | Answer the **simulated user** gave in that log. Not a human answer |
| `binary_qs[].prop_ko` | Korean question shown to participants |
| `open_qs` / `open_qs_ko` | Open-ended questions asked by Pooled Independent Matching (`questions_for_target_object_list` in its `info.json`), English and Korean |
| `n_binary_q`, `n_open_q` | Number of questions of each kind |

## Running a study

```bash
cd user_study/study1_binary_vs_open   # or study2_delivery
pip install -r requirements.txt
streamlit run app.py
```

Responses are stored in one of two places:

1. **Google Sheets (used for the paper).** Deploy `apps_script.gs` as a Google Apps
   Script web app bound to a sheet, then copy
   `.streamlit/secrets.toml.example` to `.streamlit/secrets.toml` and set the web app URL.
2. **Local SQLite (default).** Without a webhook, responses go to
   `responses_local*.db` in the study folder.

Timing (wait times, gaps between questions), texts, and the stimulus file are set in
`config.py`. Study 2 includes real waiting periods of about 1 to 3 minutes per
session, as in the paper.

## Scripts

| Script | Purpose |
|---|---|
| `prepare_stimulus_h2.py` | Builds the Study 1 stimulus file from ProCompNav and Pooled Independent Matching logs |
| `prepare_stimulus.py` | Builds the Study 2 candidate stimulus file from ProCompNav logs |
| `translate_stimulus.py` | Translates questions to Korean with an LLM (needs `OPENROUTER_API_KEY`) |
| `analyze_h2.py <responses.csv>` | Analysis for Study 1 |
| `analyze_responses.py <responses.csv>` | Analysis for Study 2 |

The preparation scripts read `info.json` files written by `run_experiments.py`:

```bash
OURS_ROOT=<ProCompNav eval folder> \
POOLED_ROOT=<Pooled Independent Matching eval folder> \
PAIRS_DIR=<folder with ep<id>_TARGET.png images> \
python user_study/scripts/prepare_stimulus_h2.py
```

The JSON files shipped here are the exact stimuli used in the paper. Use them as
they are to reproduce the studies.
